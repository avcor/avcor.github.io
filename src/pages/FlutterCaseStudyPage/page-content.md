## Business Problem

Title: Business Problem

Text 1: Digii was developing the same mobile workflows in Flutter for another product.

Text 2: Rebuilding them natively for Android would increase engineering effort, slow releases, and create long-term maintenance overhead.

## My Ownership

Title: My Ownership

- Evaluated Flutter and React Native through production-focused POCs
- Selected Flutter as the platform strategy
- Designed the Android ↔ Flutter integration architecture
- Built the communication layer between Android and Flutter
- Established an independent Android & Flutter release pipeline

## Impact

- 90 → 18 min — Android build pipeline duration, start to finish
- Independent Releases — Android and Flutter shipped separately
- Reusable Platform — Foundation for future Flutter modules
- Reduced Engineering Effort — Eliminated duplicate feature development
